## Claude Pro 充值前，先分清订阅和 API 充值

“Claude Pro 充值”经常和“Claude API 充值”混在一起，但两者不是同一项服务。

Claude Pro 是面向个人聊天用户的订阅计划，主要用于 Claude 网页端、桌面端和移动端，同时提供更多模型、Projects、Claude Code、Claude Design、Slides、Docs 等功能。Claude Max 则是在 Pro 基础上提高使用额度，分为 Max 5x 和 Max 20x。

Claude API 充值则是给开发者账户增加 API 余额，之后按照模型调用量扣费。API 余额不能自动转换成 Claude Pro 会员，购买前一定要看清页面上写的是“Claude 订阅”还是“Claude API”。

简单判断：

- 想在 Claude 对话页面里聊天、写作、编程，选择 **Claude Pro**。
- 想获得比 Pro 更高的使用容量，选择 **Claude Max 5x** 或 **Max 20x**。
- 想在自己的程序、网站或自动化脚本中调用模型，才考虑 **Claude API**。
- 购买 API 余额，不能解决 Claude 网页会员没有开通的问题。

## Claude Pro 充值的具体流程

BeWild 的 Claude 订阅不是直接给你一个共享账号，而是通过你的 Claude 账号完成升级。通常流程如下。

### 1. 选择 Claude 方案

打开 Claude 订阅页面，选择 Claude 产品，再选择 Pro、Max 5x 或 Max 20x。之后需要选择单次订阅或长期订阅。

第一次使用建议先选 1 个月。这样可以先确认账号状态、网络环境和开通流程是否适合自己。长期方案的月均价格可能更低，但平台帮助中心提醒，多月订阅涉及后续按月处理，不适合在没有确认流程前直接购买。

### 2. 登录自己的 Claude 账号

在浏览器打开 Claude 并登录你准备开通的账号。BeWild 教程建议使用 Chrome，并保持登录状态。

如果账号已经有有效的 Claude 订阅、逾期账单或正在处理的付款记录，可能无法重新开通。帮助中心建议先确认 Claude 的 Billing 页面状态，必要时等账号恢复 Free 后再尝试订阅。

### 3. 导出 Cookie

Claude Pro 的 BeWild 开通流程需要使用 Cookie-Editor 扩展，把已经登录 Claude 网页的 Cookie 导出为 JSON，再粘贴到订阅页面。

这一点和 Claude API 充值不同。API 充值通常使用 Session Key，Claude Pro 订阅则按照平台教程提交 Cookie JSON。两者不要混用，否则容易出现验证失败。

Cookie 是登录凭证的一部分。导出后不要发给客服以外的第三方，也不要截图公开，更不要把同一份 Cookie 用在其他网站。BeWild 自己的教程也提醒，Cookie JSON 只用于本次开通，应避免外发。

### 4. 验证、付款并等待开通

提交 Cookie 后，页面会先验证账号。验证通过后进入收银台，完成付款即可。

BeWild 帮助中心写明，付款后通常需要等待约 5–30 分钟，期间不要重复付款。看到平台显示成功后，可以重新登录 Claude，进入设置或 Billing 页面确认当前计划是否已经变成 Pro 或 Max。

如果付款成功但 Claude 仍显示 Free，先确认登录的是提交 Cookie 时对应的邮箱账号，再保存订单截图、支付记录和 Claude 账单页面，联系平台客服核对。
